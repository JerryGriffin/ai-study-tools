两个面向学生的 AI 学习工具：大学高数答疑，以及初高中做题 + 独立校验。 在线版直接体验；下载完整版可获得多路求解、OpenCode 免费模型和本地后端。

在线版说明：GitHub Pages 不能运行 Python 后端。在线演示使用 Pollinations 免费模型（匿名约 45 秒限 1 次）； 作业校验台的示例题带完整校验报告，自定义题使用“单路模型 + 浏览器内 SymPy”校验。完整版支持 Kilo / OpenCode 免费模型和多路复核。
图片做题：两个工具都支持上传题目截图。在线版在浏览器内用 Tesseract OCR 转成可编辑文字，完整版用 OpenCode 本机视觉免费模型识别；OCR 可能有误，请先核对识别结果。

免费模型

两个工具默认接入免费模型：Kilo Free（本地完整版默认）、Pollinations（在线版）、OpenCode 免费（安装 OpenCode 后可用）。无需 API Key。

完整版额外能力

  • 高数答疑室：Kilo / OpenCode 免费模型，自动连接本地代理，SSE 流式输出；图片自动路由到 OpenCode 视觉免费模型；
  • 作业校验台：多路独立求解 + 交叉复核 + SymPy 校验，支持自定义题目；图片先识别成文字再走完整校验流水线；
